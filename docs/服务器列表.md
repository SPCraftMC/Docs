# 服务器列表

这里是我们目前开设的服务器列表，包含了地址信息及一些说明。

!!! danger

    由于 Mojang 的更新破坏了基岩版连接到双栈网络服务器的兼容性，如果阁下无法连接，请尝试自行解析 DNS 地址获取 IP，如果阁下不明白这是什么意思，可以加入玩家社区求助。

## 纯净生存服 & 创造服

这些服务器均通过代理的大厅加入。
当前服务端版本为 Java 版 26.2。
对于 Java 版，我们支持 1.16.5+ 的客户端，基岩版默认保持最新。

| 地区 | 客户端版本 | 接入域名             | 端口      |
| ---- | ---------- | :------------------- | --------- |
| 全球 | Java 版    | `spcraft.cn`         | 无（SRV） |
| 全球 | 基岩版     | `bedrock.spcraft.cn` | 19132     |

对于 Java 版，阁下也可以通过以下地址快速加入对应子服务器：

| 地区 | 客户端版本 | 接入域名          | 子服务器 | 类型     |
| ---- | ---------- | :---------------- | -------- | -------- |
| 全球 | Java 版    | `sur1.spcraft.cn` | 云之域 1 | 纯净生存 |
| 全球 | Java 版    | `sur2.spcraft.cn` | 云之域 2 | 纯净生存 |
| 全球 | Java 版    | `sur3.spcraft.cn` | 生存服 3 | 纯净生存 |
| 全球 | Java 版    | `crt.spcraft.cn`  | 创造服   | 创造     |
