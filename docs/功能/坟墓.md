# 坟墓

~~哎你怎么似了！~~

## 命令列表

| 命令                          | 说明              |
|-----------------------------|-----------------|
| /graves list                | 获取因自己死亡而产生的坟墓列表 |
| /graves tp                  | 传送到自己离自己最近的坟墓 |

## 功能说明

当玩家死亡时物品不会散落一地，而会产生一个坟墓。  
坟墓包含了玩家的背包内容。  
坟墓会在 **86400分钟(30天)** 后消失，消失后不可找回。
使用 ++shift+rbutton++ 点击坟墓以拾取并清除坟墓。

尽管有坟墓，阁下还是无法逃离死亡惩罚，所以，切记小心行事！
