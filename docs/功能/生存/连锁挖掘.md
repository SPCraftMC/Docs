# 连锁挖掘

一次性挖掘多个方块。

## 功能说明

快速挖掘可以通过持有指定工具并开启连锁或安装模组后按住快捷键后破坏方块触发。

## 支持的连锁列表

默认最大可连锁方块数为 100 个方块，搜索半径为 1 个方块。

| 分类名称   | 适用方块                                                                                                               | 所需工具                                               | 特殊限制 / 覆盖配置        |
| :--------- | :--------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------- | :------------------------- |
| 矿石       | `#c:ores` (所有矿石)                                                                                                   | `#minecraft:pickaxes` (任意镐类)                       | 无                         |
| 混凝土粉末 | 混凝土粉末类方块                                                                                                       | `#minecraft:shovels` (任意锹类)                        | 无                         |
| 草与植物   | `#minecraft:edible_for_sheep` `minecraft:tall_grass` `minecraft:large_fern` `minecraft:bush` `minecraft:dead_bush`     | 无限制（允许空手或任意工具）                           | 最大连锁数：50 搜索半径：3 |
| 树叶       | `#minecraft:leaves` (所有树叶)                                                                                         | `#minecraft:hoes` (任意锄类) `minecraft:shears` (剪刀) | 无                         |
| 原木与蘑菇 | `#minecraft:logs` (所有原木) `minecraft:mushroom_stem` `minecraft:brown_mushroom_block` `minecraft:red_mushroom_block` | `#minecraft:axes` (任意斧类)                           | 无                         |
| 下界岩石   | `#minecraft:base_stone_nether` (下界基础岩石) `minecraft:smooth_basalt`                                                | `#minecraft:pickaxes` (任意镐类)                       | 无                         |
