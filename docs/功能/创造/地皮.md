# 地皮

造一片，自由天地。

## 命令列表

| 命令           | 说明                         |
| -------------- | ---------------------------- |
| /plot auto     | 自动领取一块空闲地皮         |
| /plot claim    | 领取当前站立的空闲地皮       |
| /plot home     | 回到自己的地皮               |
| /plot visit    | 传送至指定玩家的地皮         |
| /plot merge    | 向看向的方向合并相邻地皮     |
| /plot setbiome | 修改地皮的生物群系           |
| /plot time     | 设置地皮的固定时间           |
| /plot weather  | 设置地皮的天气               |
| /plot add      | 添加协作者权限（仅在线有效） |
| /plot trust    | 添加信任者权限（永久有效）   |
| /plot remove   | 撤销玩家的地皮权限           |
| /plot deny     | 阻止指定玩家进入地皮         |
| /plot undeny   | 解除玩家的禁入限制           |
| /plot clear    | 清空地皮上的所有建筑         |
| /plot delete   | 释放并彻底删除地皮           |

## 功能说明

前往创造地皮世界后，使用 `/plot auto` 即可自动领取一块属于自己的地皮。
若已站在未被领取的空地上，使用 `/plot claim` 即可直接领取。

### 传送

- 使用 `/plot home` 或 `/plot h` 即可快速传送回自己的地皮。
- 使用 `/plot visit <玩家名>` 或 `/plot v <玩家名>` 即可前往拜访其他阁下的地皮。

### 合并

在创造服建造大型项目时，可领取多块相邻地皮进行合并。
站在已领取的地皮边缘，看向需要合并的自留地皮方向，执行命令 `/plot merge` 即可打通地皮。

### 环境

创造服支持高度自由定制地皮环境：

- **生物群系**：`/plot setbiome <群系名称>` 修改地皮群系（如 `plains`、`ocean`、`desert` 等）。
- **固定时间**：`/plot time <时间/ticks>` 设置昼夜环境（如 `/plot time day` 或 `/plot time night`）。
- **天气设置**：`/plot weather <sun/rain/clear>` 设置降水或晴朗状态。

### 权限

使用 `/plot add <玩家名>` 或 `/plot trust <玩家名>` 可赋予其他阁下协同建造权限。

- **协作者（add）**：仅在地皮主人在线时拥有建造与编辑权限。
- **信任者（trust）**：无论地皮主人是否在线，均随时拥有完整建造与编辑权限。

使用 `/plot remove <玩家名>` 即可撤销该玩家的所有权限。

### 禁入

使用 `/plot deny <玩家名>` 可将恶意干扰的玩家拉入黑名单，被限制者将无法踏入地皮范围。
如需解除限制，使用 `/plot undeny <玩家名>` 即可。

### 重置

!!! warning

    地皮清空与删除操作不可逆，请谨慎执行。

- **清空地皮**：使用 `/plot clear` 可还原地皮内所有方块至初始平地状态，但保留地皮归属权。
- **删除地皮**：使用 `/plot delete` 会清空地皮内容并放弃归属权，使其变回未领取的空地。
